# Finora

> Your Personal Finance OS

Finora is a modern AI-powered personal finance platform that helps individuals and families manage every aspect of their financial life.

---

## Features

- 💰 Expense Tracking
- 📊 Budget Management
- 🏦 Loan Management
- 📈 Investment Portfolio
- 🛡 Insurance Tracker
- 🎯 Financial Goals
- 💳 Net Worth Dashboard
- 🤖 AI Financial Insights
- 📅 Bill Reminders
- 📤 Excel & CSV Export

---

## Tech Stack

Frontend

- React
- TypeScript
- TailwindCSS
- ShadCN UI

Backend

- NestJS
- PostgreSQL
- Prisma

Infrastructure

- Docker
- Redis
- Supabase
